









-- MATERIAL SYMBOLS --
This page uses google Material Symbols as icons. To make the page self contained, the font was downloaded and added to the "font" subfolder of "stylesheet".
To make the viewer slimmer by using the google CDN: remove the "font" subfolder, and substitute 
<link type="text/css" rel="stylesheet" href="stylesheet/fonts/material-symbols-local.css"/>
with
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />
